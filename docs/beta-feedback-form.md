# Private beta feedback form

Create this form in a private service and export only anonymized counts. Make tester ID required; make name/email optional or collect them separately from test evidence.

## Identification

1. Tester ID (`T-01`, etc.).
2. Task day (`1–14` or `unscheduled`).
3. Privyetik version and build shown under Settings → App Information.
4. Device manufacturer/model and Android version.
5. Install source: Google Play closed test / web browser.

## Result

6. Which area did you use? Onboarding, auth, placement, vocabulary, study/review, dictionary, grammar/AI, alphabet, stats, sync, reminders, share-to-app, privacy/deletion, other.
7. Did you finish the task? Yes / Partly / No.
8. Rate ease of use from 1 (blocked) to 5 (clear).
9. What did you expect to happen?
10. What actually happened?
11. Can you reproduce it? Always / Sometimes / Once / Not applicable.
12. Did you lose progress or become unable to continue? Yes / No.
13. Safe screenshot or screen recording (optional; remove email and personal content).
14. What one improvement would help most?
15. May the developer contact you privately for reproduction details? Yes / No.

## Final-day additions

- Which features did you use more than once?
- What was most useful?
- What was least trustworthy or clear?
- Did notifications arrive at the expected time?
- Did your data persist after restart and, if tested, sync across devices?
- Would you keep using Privyetik? Why?
- Is any issue serious enough to block release?
