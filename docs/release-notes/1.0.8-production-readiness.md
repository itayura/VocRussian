## Tester-facing notes

- Added permanent self-service account deletion in the app and on the web.
- Clarified privacy, reminder data, retention, and account controls.
- Added version and build details to Settings for better issue reports.
- Improved reliable scheduled reminders and delivery diagnostics.
- Updated Play Store feature artwork and release checks.

## Operator deployment order

1. Push Supabase migrations, including `20260809180107_fix_reliable_scheduled_reminder_body.sql`.
2. Deploy `delete-account` with the existing Edge Functions workflow.
3. Deploy Pages and verify `privacy.html` and `delete-account.html` publicly.
4. Add the public deletion URL and truthful Data Safety answers in Play Console.
5. Run repository/CI checks and smoke-test a disposable account.
6. Build/upload the signed AAB to the existing closed track through the guarded manual workflow.
7. Wait for **Available to testers**, then start the evidence period.

Do not publish directly to production from this repository. Production access and rollout remain explicit Play Console decisions after the new closed-test evidence is complete.
